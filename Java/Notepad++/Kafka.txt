Installation guide

1. download Kafka zip file from official websit(kafka.apache.org/quickstart)
2. extract file
3. start Zookeeper
   run command: bin\windows\zookeeper-server-start.bat config\zookeeper.properties         //open cmd in same location of bin & config
4. start Kafka server
   run command: bin\windows\kafka-server-start.bat config\server.properties

Using kafka with console

1. create new topic with kafka-topics
2. produce example message with kafka-console-producer
3. consume the message with kafka-console-consumer


Step1:
bin\windows\kafka-topics.bat --create --topic user-topic --bootstrap-server localhost:9092

Step2:
bin\windows\kafka-console-producer.bat --topic user-topic --bootstrap-server localhost:9092
>hello
>this is producer-consumer demo

Step3:
>bin\windows\kafka-console-consumer.bat --topic user-topic --from-beginning --bootstrap-server localhost:9092
>hello
>this is producer-consumer demo

>bin\windows\kafka-console-consumer.bat --topic user-topic --from-beginning --bootstrap-server localhost:9092
>hello
>this is producer-consumer demo
